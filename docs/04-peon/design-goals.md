# 苦工设计目标

---

## 视觉参考（灵感，非 1:1 商用复制）

- 矮胖、弓背
- 大头、绿皮（涂装或 PLA 色）
- 粗腿、大脚
- 肩扛镐子
- 语音：劳动感音效（避免直接商用暴雪原声）

---

## 硬约束（机器人能走）

| 约束 | 数值级建议 |
|------|------------|
| 整机高度 | 尽量接近 Open Duck ~42cm，改矮需重训 |
| 头部额外质量 | < 80g（空心壳） |
| 镐子质量 | < 30g |
| 电池位置 | 腰/背低位 |
| 额外舵机 | 路线 A：0；路线 C：+4~6 |
