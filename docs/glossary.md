# 术语表（零基础）

阅读文档时遇到不懂的词，来这里查。

---

## 机器人与机械

| 术语 | 通俗解释 |
|------|----------|
| **双足机器人** | 用两条腿走路的机器人，像人一样 |
| **舵机 / Servo** | 一种能转到指定角度的电机；本项目用 **串口总线舵机**，可串联、可设 ID |
| **STS3215** | 飞特牌舵机型号，Open Duck Mini 用 14 个 |
| **自由度 DOF** | 关节可动的方向数量；一条腿约 5 个主动关节 |
| **热熔螺母** | 铜螺母，用烙铁压进 3D 打印孔，用来拧螺丝 |
| **PLA / TPU** | 3D 打印塑料；PLA 硬，TPU 软（用来做防滑脚底） |
| **STL** | 3D 打印模型文件格式 |
| **BOM** | 物料清单，要买什么零件的表 |
| **质心** | 重量中心；太高或太靠前容易摔 |

## 电子

| 术语 | 通俗解释 |
|------|----------|
| **树莓派 Raspberry Pi** | 小型电脑；本项目用 **Pi Zero 2 W** 装在机器人头里 |
| **IMU** | 惯性测量单元，感知倾斜、旋转；型号 BNO055 |
| **BMS** | 电池保护板，防止过充过放 |
| **UBEC** | 把电池电压降到 5V 给树莓派供电 |
| **GPIO** | 树莓派针脚，接开关、LED、天线舵机 |
| **I2C / UART** | 两种通信方式；IMU 用 I2C，舵机总线用 UART |
| **杜邦线** | 彩色跳线，连接模块 |

## 软件与 AI

| 术语 | 通俗解释 |
|------|----------|
| **仿真 Simulation** | 在电脑里模拟物理世界，不用真机器人 |
| **RL 强化学习** | 让程序通过「试错 + 奖励」学会走路 |
| **PPO** | 一种常用的 RL 算法 |
| **MuJoCo** | 物理仿真引擎 |
| **MJCF** | MuJoCo 的机器人模型描述文件 |
| **策略 Policy** | 训练得到的「怎么动」的规则，通常是神经网络 |
| **ONNX** | 导出后的策略文件格式，树莓派能加载 |
| **Sim2Real** | 仿真里练的策略部署到真机 |
| **50 Hz** | 每秒更新 50 次控制指令 |
| **num-envs** | 并行仿真的机器人个数；越大越快但越吃显存 |
| **冒烟测试 Smoke test** | 极短运行，只为确认环境没装错 |

## 工具与环境

| 术语 | 通俗解释 |
|------|----------|
| **Git** | 版本管理工具，下载代码用 |
| **GitHub** | 放代码的网站；本项目的文档站用 **GitHub Pages** |
| **WSL2** | Windows 里的 Linux 子系统；训练建议在 WSL 里做 |
| **CUDA** | NVIDIA 显卡计算平台 |
| **PyTorch** | 深度学习框架；训练要用 |
| **uv** | Python 包管理工具；`microduck_rl` 官方用它 |
| **终端 / 命令行** | 黑窗口输入文字命令的地方 |
| **Bambu Studio** | 拓竹打印机配套切片软件 |

## 项目特有

| 术语 | 解释 |
|------|------|
| **Open Duck Mini** | 开源 DIY 双足鸭机器人（42cm） |
| **Microduck** | Hugging Face 卖的成品小鸭子（25cm，硬件闭源） |
| **microduck_rl** | 训练走路策略的 GitHub 仓库 |
| **Runtime** | 在树莓派上跑策略、控制舵机的程序 |
| **苦工 / Peon** | 魔兽世界兽人苦工造型；本项目的角色化目标 |
