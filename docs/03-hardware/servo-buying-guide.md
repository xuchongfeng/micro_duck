# STS3215 舵机采购避坑

Open Duck Mini **必须使用** Feetech **STS3215** 串口总线舵机，**不能**用普通 PWM 舵机替代。

---

## 正确型号

| 项目 | 要求 |
|------|------|
| 品牌 | Feetech（飞特） |
| 型号 | **STS3215** |
| 料号 | **ST-3215-C001**（常见 7.4V 19kg·cm 磁编码双轴 TTL 版） |
| 电压 | **6–7.4V**（与 2S 电池匹配） |
| 扭矩 | 约 19 kg·cm @ 7.4V |
| 协议 | **TTL 半双工串口**（Dynamixel 2.0 类似，非 PWM） |
| 数量 | **14** |

官方参数：[飞特 STS3215 产品页](https://www.feetech.cn/74v-19-kgcm-plastic-case-metal-tooth-magnetic-code-double-axis-ttl-series-steering-gear.html)

## 已确认的坑

### ❌ ¥8「虚拟舵机」

- 淘宝部分链接标价 ¥8，评价规格写 **`ST-3215-C066（虚拟舵机）`**
- 用于仿真/展示，**不是实体舵机**
- **不要购买**

### ❌ 普通 PWM 舵机

- SG90、MG996R 等 **不能** 接入 Waveshare 总线驱动板跑 Runtime
- 仅 9g 舵机用于 **天线**（PWM 接 Pi GPIO）

### ❌ 电压/齿比错误子型号

- 购买前确认页面写 **7.4V**、**19kg**、**磁编码**、**串口/TTL**
- 不确定时问客服要 **C001**  datasheet

**到货检查：**

- [ ] 包装有 Feetech 标识
- [ ] 重量约 **55g±** / 个
- [ ] 线长约 15 cm，3Pin 串口线
- [ ] 附塑料舵盘与塑料螺丝
- [ ] 默认 ID 多为 1（需自行改 ID）

---

## 与 Microduck 的关系

Microduck 使用 **Dynamixel XL330**，与 Open Duck Mini 的 **STS3215 不通用**。本项目按 Open Duck 路线采购 **STS3215 ×14**。
