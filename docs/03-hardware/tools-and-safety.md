# 工具、安全与工作区

---

## 一、工作区布置

| 区域 | 用途 |
|------|------|
| 打印区 | A1 打印机，通风，远离易燃物 |
| 焊接区 | 排烟、灭火器、隔热垫 |
| 组装台 | 良好照明、零件盒分格（左/右舵机分开放） |
| 电脑区 | WSL 训练 + Bambu Studio |

建议准备 **分格零件盒**，标签：`ID10-14`、`ID20-24`、`ID30-33`。

---

## 二、个人防护

| 活动 | 防护 |
|------|------|
| 3D 打印 | 不徒手撕高温件；PLA 通风 |
| 焊接 | 护目镜、通风；勿点易燃物 |
| 上电调试 | 护目镜可选；手指远离舵机 |
| 锂电池 | 防短路盒；损坏电芯勿用 |

---

## 三、锂电池安全（必读）

- 不穿刺、不浸水、不过充
- 充电时 **人在场**
- 鼓包电芯 **立即停用** 并按规定废弃
- 2S 组装错误可能起火 — 焊完测 BMS 再合盖

---

## 四、舵机测试安全

- `check_motors` 时 **托起机身**，脚离地
- 长发、绳带远离齿轮
- 异常尖叫/过热 → **立即断电**

---

## 五、儿童与宠物

双足机器人不是玩具；运行时不要靠脸或手抓运动部件。

---

## 六、急停

在电池正极串联 **易触及的电源开关**，或随时可拔 XT30。
