# 拓竹 A1 打印指南

打印机：**Bambu Lab A1**（256×256×256 mm，近程挤出，适合 PLA + TPU）

STL 来源：克隆官方仓库后使用 `Open_Duck_Mini/print/` 目录。

```bash
git clone -b v2 --depth 1 https://github.com/apirrone/Open_Duck_Mini.git
# STL 路径：Open_Duck_Mini/print/*.stl
```

---

## 一、官方材料要求（必须遵守）

| 材料 | 件数 | 填充率 | 用途 |
|------|------|--------|------|
| **PLA** | 49 件 | **15%** | 全部结构件 |
| **TPU 95A** | 2 件 | **40%** | 仅 `foot_bottom_tpu.stl` ×2 |

> 来源：[官方 print_guide](https://github.com/apirrone/Open_Duck_Mini/blob/v2/docs/print_guide.md)

## 二、Bambu Studio 通用参数（PLA 结构件）

在 Bambu Studio 中新建 **PLA 结构件** 工艺预设，或按下列覆盖默认值：

### 2.1 打印机与喷嘴

| 参数 | 推荐值 |
|------|--------|
| 打印机 | Bambu Lab A1 |
| 喷嘴 | 0.4 mm 硬化钢（默认即可） |
| 打印板 | 光面 PEI / 纹理 PEI（建议纹理板增粘） |
| 打印板类型 | 在软件中选对应板型 |

### 2.2 层高与壁厚

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 层高 | **0.20 mm** | 强度与速度平衡；外观件可用 0.16 |
| 首层层高 | 0.20 mm | |
| 墙层数 | **3** | 受力部位（脚、髋）勿少于 3 |
| 顶/底层 | 4 层 | |

### 2.3 填充（对齐官方）

| 参数 | 推荐值 |
|------|--------|
| 稀疏填充密度 | **15%** |
| 稀疏填充图案 | **Gyroid** 或 Grid（Gyroid 抗扭更好） |
| 填充组合 | 默认 |

### 2.4 速度（A1 默认可略降首打）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 外墙速度 | 80–120 mm/s | 首打建议 80 |
| 内墙/填充 | 150–200 mm/s | 可用默认值 |
| 首层速度 | **30–50 mm/s** | 提高附着力 |
| 悬垂降速 | 开启 | |

### 2.5 温度（按耗材品牌微调）

| 参数 | eSun PLA+ 参考 | 拓竹 PLA 参考 |
|------|----------------|---------------|
| 喷嘴 | 210–220 °C | 220 °C |
| 热床 | 55–60 °C | 60 °C |
| 腔温 | 无（A1 开放式） | — |

> 新耗材建议打印温度塔，以不粘床、层结合良好为准。

### 2.6 附着与支撑

| 参数 | 推荐值 |
|------|--------|
| 裙边 Brim | **开启**，宽度 5–8 mm（大脚件建议开） |
| 筏 Raft | 一般关闭 |
| 支撑 | **尽量自动仅必要时**；轴承孔、舵机孔面朝上减少支撑 |
| 支撑类型 | 树状支撑（Bambu 默认） |

### 2.7 冷却

| 参数 | 推荐值 |
|------|--------|
| 部件冷却风扇 | 100%（PLA） |
| 悬垂风扇 | 开启 |

### 2.8 精度

| 参数 | 推荐值 |
|------|--------|
| 尺寸补偿 | 0（首打后卡尺测量再微调） |
| 精确壁 | 开启 |
| 接缝位置 | 对齐或背面 |

## 三、TPU 脚垫参数（`foot_bottom_tpu.stl`）

近程挤出 A1 打 TPU 比远程机容易，但仍需放慢：

| 参数 | 推荐值 |
|------|--------|
| 材料 | **TPU 95A**（Shore 95A，如 eSun eLastic / 拓竹 TPU） |
| 填充 | **40%**（官方） |
| 喷嘴温度 | 220–235 °C |
| 热床 | 50–55 °C |
| 打印速度 | **20–35 mm/s**（全程偏慢） |
| 加速度 | 降至 2000–3000 mm/s² |
| 回抽 | 0.4–0.8 mm，速度 20–30 mm/s |
| 风扇 | **30–50%**（TPU 过冷易层间弱） |
| 干燥 | 建议烘料 60°C 4–6 h 或密封盒 |

**与 PLA 底合体：** 打印 `foot_bottom_pla.stl` 后，用 **M3×6** 与 TPU 层锁在一起（见组装指南）。

## 四、大件与摆放建议

| 文件 | 约大小 | 摆放建议 | 预估时间 |
|------|--------|----------|----------|
| `head.stl` | 最大 | 平整面朝下，开 Brim | 6–10 h |
| `trunk_top.stl` | 大 | 最大平面朝下 | 3–5 h |
| `body_back.stl` | 大 | 背面朝下 | 3–4 h |
| `foot_top.stl` | 中 | 脚底面朝下 | 1–2 h |
| `leg_spacer.stl` | 小 | 任意，先打验孔 | 20–40 min |

**A1 成型尺寸 256³：** `head.stl` 无需拆件即可单盘打印（官方设计适配桌面级打印机）。

### 摆放原则

1. **最大平面贴热床** — 减少翘曲
2. **轴承孔、舵机轴孔竖直向上** — 圆度更好
3. **受力方向沿 Z 层纹** — 轴孔处层纹垂直于螺丝方向
4. 不确定时对照 [Onshape CAD](https://cad.onshape.com/documents/64074dfcfa379b37d8a47762/w/3650ab4221e215a4f65eb7fe/e/0505c262d882183a25049d05)

## 五、热熔螺母安装（打印后必做）

许多孔位需压入 **M3×4×5 热熔螺母**：

| 零件 | 螺母数量（约） |
|------|----------------|
| trunk_bottom | 6+ |
| foot_top / foot_bottom | 各 2+ |
| leg_spacer | 每侧 2，共 4 |
| head / body_middle | 多处 |

**安装方法：**

1. 烙铁头或热熔螺母铜套加热至 **250–280°C**
2. 垂直压入，与孔平面齐平
3. 禁止歪斜；冷后试拧 M3 螺丝应顺滑不晃

## 六、打印后质检清单

每件打印完成后检查：

- [ ] 尺寸：舵机安装槽能否卡入 STS3215 外壳
- [ ] M3 孔：螺丝能拧入，不过紧不过松
- [ ] 轴承位 608ZZ：8mm 孔可压入或有 0.1mm 余量可砂
- [ ] 无严重翘曲：放在平面上四角贴床
- [ ] 层间开裂：尤其 `leg_spacer`、髋支架
- [ ] TPU 底：防滑纹清晰，与 PLA 底孔对齐

**不合格处理：** 功能性孔位件 **重打**，不要强行扩孔到结构发脆。

## 八、Bambu Studio 操作流程（逐步）

1. **导入 STL**：文件 → 导入 → 选择 `print/` 下文件
2. **批量盘**：同批零件排满 256×256 盘（注意间距 ≥5 mm）
3. **选耗材**：盘 1–3 用 PLA；脚垫单独一盘 TPU
4. **工艺**：套用本文「PLA 结构件」或「TPU 脚垫」参数
5. **切片**：检查预览层纹与支撑位置
6. **发送打印**：局域网发 A1 或 SD（A1 支持 WiFi）
7. **首层观察**：前 5 分钟盯首层附着
8. **贴标签**：打印袋写明件名（left/right 勿混）

## 九、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 翘角 | 床温低 / 无 Brim | 加 Brim、擦酒精、升床温 |
| 舵机槽太紧 | 收缩 / 壁厚 | 砂纸修 0.2mm 或略扩孔 |
| 舵机槽太松 | 尺寸偏大 | 加垫片或重打 |
| TPU 堵头 | 速度太快 / 潮湿 | 减速、烘料、清理喷嘴 |
| 层间裂 | 冷却过强 / 填充低 | 升温度或增外墙圈数 |
| 头件失败 | 面积大翘曲 | Brim 10mm、降外墙速度 |
