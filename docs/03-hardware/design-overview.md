# 硬件与设计总览

本文说明：**要买什么、要设计什么、什么不用设计**。基座为 [Open Duck Mini v2](https://github.com/apirrone/Open_Duck_Mini/tree/v2)，苦工为后续增量。

---

## 一、你需要完成的设计工作

| 类别 | 标准鸭（Phase 3） | 苦工（Phase 4） |
|------|-------------------|-----------------|
| **机械 CAD** | ❌ 不需要 — 用官方 STL | ⚠️ 路线 A 仅外壳；路线 B 需改比例 |
| **电路设计** | ❌ 不需要 — 按官方接线图 | ❌ 一般不改，最多加 LED/喇叭 |
| **3D 打印** | ✅ 打印官方 36 种 STL | ✅ 额外打印苦工外壳 |
| **舵机标定** | ✅ 14 个 ID + 零位 | ✅ 同左（若改机械需重标） |
| **RL 仿真模型** | ❌ 可用上游 | ✅ 路线 B+ 需自建 MJCF |
| **控制策略** | ❌ 可用官方 ONNX | ✅ 路线 B+ 需重训 |

**结论：** 首台机器 **不需要自己做机械设计**，只需采购 + 打印 + 组装。苦工「设计」分阶段叠加。

## 二、整机架构（设计边界）

```
                    ┌─────────────────┐
                    │  头部（Pi/IMU）  │  ← 3× STS3215 + 2× 9g 天线舵机
                    └────────┬────────┘
                             │ neck_pitch (ID:30) @ 躯干
                    ┌────────┴────────┐
                    │   躯干 trunk     │  ← 608ZZ 轴承 ×3
                    └───┬───────┬───┘
                        │       │
              左腿 5DOF │       │ 5DOF 右腿
              ID 20-24  │       │ ID 10-14
                        │       │
                    ┌───┴───┐ ┌─┴───┐
                    │ 脚×2  │ │脚×2 │  ← TPU 底 + 微动开关
                    └───────┘ └─────┘

电控仓：body_* 外壳内 — 电池 2S、BMS、UBEC、舵机驱动板
```

- **主动关节**：14 × STS3215（串口总线，不可 3D 打印）
- **被动/结构**：全部来自官方 `print/*.stl`（可打印）
- **算力**：树莓派 Zero 2 W（跑 Runtime + ONNX 策略）

## 四、苦工额外设计清单（Phase 4）

### 路线 A — 仅外观（推荐先做）

| 设计产出 | 工具 | 说明 |
|----------|------|------|
| 苦工头壳 STL | Fusion 360 / Blender | 套在官方 `head.stl` 外或替换外观件 |
| 肤色涂装方案 | — | 喷漆或双色 PLA |
| 镐子道具 STL | 同上 | 轻量空心，<30g |
| 语音触发表 | 表格即可 | 按钮/NFC → 音效 |

**不动** 连杆长度 → **不强制** 重训策略。

### 路线 B — 改比例（正经苦工步态）

| 设计产出 | 说明 |
|----------|------|
| 修改后 CAD | 大腿/小腿长度、躯干倾角、脚板面积 |
| 质量预算表 | 各段预估质量（仿真必填） |
| MuJoCo MJCF | 新连杆、碰撞体、执行器 |
| 3D 打印验证件 | 先打单腿试装再全打 |

### 路线 C — 手臂（二期）

| 设计产出 | 说明 |
|----------|------|
| 肩/肘机构 | +4~6 舵机，建议 9g 或 STS3215 小号 |
| 镐子关节 or 固定 | 影响质心，需仿真 |

## 五、设计约束（避免翻车）

| 约束 | 原因 |
|------|------|
| 头部空心薄壁 | 头重易摔 |
| 电池放腰/背低位 | 降低质心 |
| 镐子 <30g | 肩舵机负载有限 |
| 热熔螺母孔不打歪 | M3 孔位来自官方 STL，少改孔 |
| 舵机零位在组装前标定 | 装错零位腿会反弯 |
| STS3215 必须 C001 7.4V | 电压/协议不对会烧驱动 |

---

## 六、与仿真的关系

即使先买硬件，也建议 **Phase 1 仿真已通过**。硬件设计（尤其苦工路线 B）与 MJCF 应 **同一套尺寸**，否则训练与真机不一致。
