## 三、采购顺序建议

```
第 1 批（可与仿真并行）：PLA + TPU → A1 试打 foot_top、leg_spacer
第 2 批（仿真 smoke 通过后）：STS3215 ×14 + 驱动板 + 轴承 + 开关
第 3 批：Pi Zero 2W + BNO055 + 电源件 + SD
第 4 批：缺件补购（螺丝、线材）
```

## 四、不要买

| 商品 | 原因 |
|------|------|
| ¥8「STS3215」虚拟舵机 | 非实体或假货 |
| ST-3215-C066 等仿真 SKU | 评价已标注虚拟 |
| Microduck 整机当 DIY 零件拆 | 硬件闭源，无法替代 Open Duck STL |
| 无牌 18650 | 起火风险 |
| 3GB 以下杂牌舵机当 STS3215 用 | 协议/扭矩不符 |
