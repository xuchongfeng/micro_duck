# Sim2Real 微调

仿真或官方策略上真机后，常需 **小步调整** 才能稳走。

---

## 常见差距原因

| 原因 | 表现 | 处理 |
|------|------|------|
| 关节偏置未写 config | 站姿歪 | `find_soft_offsets.py` |
| 地面摩擦与仿真不同 | 打滑、摔 | 换地面、重训 domain rand |
| 电池电压低 | 无力 | 充电、换电 |
| 自训 ONNX 未 export 归一化 | 乱扭 | 重新 `export.py` |
| 质心因线材/外壳变化 | 前后倾 | 理线、减重头部 |

---

## 调整顺序

```text
1. check_motors 全通过
2. duck_config 偏置
3. 官方 BEST_WALK_ONNX_2 能否走
4. 再走自训策略
5. 仍不行 → 加训或改 MJCF 质量
```

---

## 域随机化重训（进阶）

在 `microduck_rl` 训练配置中已有 friction、电压 等随机化。真机差太多时：

- 加大摩擦/延迟随机范围
- 在仿真 MJCF 中增加与真机一致的质量
- 1060 上 `128 env` 再训一版

## 日志与对比

同一 ONNX 在：

1. `infer_policy.py`（PC 仿真）
2. `v2_rl_walk_mujoco.py`（Pi 真机）

对比行为。仿真好、真机差 → 物理/偏置问题；都差 → 策略本身欠训。
